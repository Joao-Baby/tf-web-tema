# Descrição do Projeto:

Este projeto tem como objetivo o desenvolvimento de um sistema web voltado para o público infantil e familiar, oferecendo uma interface intuitiva, moderna e acessível.
Nesta etapa do trabalho foram desenvolvidos os wireframes do sistema utilizando o Figma, permitindo o planejamento visual das páginas, organização dos elementos e definição do fluxo de navegação da aplicação.
O projeto contempla tanto as telas principais para os usuários quanto a área administrativa do sistema.

# Wireframes

Os wireframes foram desenvolvidos no Figma com o objetivo de estruturar:

- Layout das páginas;
- Organização das informações;
- Navegação entre telas;
- Fluxo de interação do usuário;
- Área administrativa do sistema.
